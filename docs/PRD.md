# PRD: Note-a-Style (노터스타일)

> Product Requirements Document v1.2
> 최종 업데이트: 2026-02-26
> 예비창업패키지 사업계획서 내용 반영

---

## 1. 제품 개요

### 1.1 제품명
**Note-a-Style (노터스타일)** -- "시술 기록의 신"

### 1.2 한줄 요약
뷰티샵(헤어/네일/피부/두피관리)의 **시술 기록 관리와 AI 포트폴리오 생성** 플랫폼

### 1.3 핵심 포지셔닝
기존 CRM(핸드SOS, 헤어짱, 스마일패드, 뷰카 등) 위에 얹어지는 **프리미엄 애드온**.
예약관리가 아닌 **시술 내용 기록과 AI 포트폴리오**에 집중.

### 1.4 Value Chain
```
원장님 (매장 운영) ←→ 디자이너님 (시술 기록) ←→ 고객님 (서비스 수혜) ←→ 기자재 사장님 (자재 공급)
```
이 4자를 하나의 플랫폼에서 연결하여 통합적인 서비스 생태계 조성.

## 2. 시장 배경 및 Pain Point

### 2.1 산업 규모
- 국내 헤어샵(미용실) 총 **112,464개**, 생활서비스업종 중 두 번째로 큰 비중(**21.5%**)
- 헤어샵 시장의 연 매출 규모 약 **6조 원 이상**, 기자재 비용 약 10% → 기자재 시장 약 **6,000억 원**
- 분기당 신규 미용실 오픈 약 **1,500개 이상** (출처: 통계청, 2023 1분기~2024 1분기 기준)
- 서울 압구정부터 지방 읍내까지 전국에 분포
- K-뷰티는 세계적 영향력을 보유하지만 디지털/전산화가 크게 부족

### 2.2 현재 문제점

#### 획일화된 솔루션
- 기존 솔루션(핸드SOS, 헤어짱, 스마일패드, 뷰카, 공비서, 토스플레이스 등)은 **예약관리에만 집중**
- 관리 업무, 홍보/마케팅, 기자재 소싱을 모두 별도로 관리 → 비용 증가

#### 악순환 구조 (Vicious Cycle)
```
과도한 마케팅 비용 (인플루언서, 블로그, SNS)
    → 서비스 단가 상승
    → 디자이너 급여 절감
    → 기자재 비용 절감 (저렴한 재료 사용)
    → 소비자에게 피해 전가
    → 더 자극적인 마케팅 필요
    → (반복)
```

#### 구체적 문제
| 문제 | 설명 |
|------|------|
| 바가지 시술 | 외국인/내국인 가리지 않는 과잉 청구 |
| 전문성 부족 | 소비자 피해로 이어지는 비전문적 시술 |
| 비전문적 고객관리 | 기억이나 메모에 의존하는 고객 히스토리 관리 |
| 실력 검증 어려움 | 디자이너 역량을 객관적으로 판단할 수 없음 |
| 계약 부조리 | 디자이너를 착취하는 점주의 불공정 계약 |
| 깜깜이 기자재 시장 | 가격 정보 부족, 합리적 구매 어려움 |
| "샵 유목민" 현상 | 만족스러운 매장을 찾지 못해 떠도는 소비자 |

#### 기능별 상세 비교 (노터스타일 vs 헤어짱 vs 핸드SOS)

| 구분 | 세부 기능 | 노터스타일 | 헤어짱 | 핸드SOS |
|------|----------|-----------|--------|---------|
| 예약 관리 | 예약보드 (기본 예약 관리) | 제공 | 제공 | 제공 |
| 예약 관리 | Drag & Drop 예약변경 | 제공 (예정) | 제공 | 제한적 제공 |
| 예약 관리 | 네이버 예약 등 외부 플랫폼 연동 | 제공 (예정) | 제공 | 일부 제한적 제공 |

| 고객 관리 | 초상권 보호 (AI Face Swap) | **AI 페이스스왑 적용 (법률검토 완료)** | 미제공 | 미제공 |
| 마케팅 지원 | 고객 리뷰 사진 콘텐츠 제작 지원 | **AI를 활용한 자동화 콘텐츠 제작** | 미제공 | 미제공 |
| 마케팅 지원 | 스타일 미리보기 (AI 스타일러) | AI 기반 스타일 미리보기 제공(예정) | 미제공 | 미제공 |
| 기자재 관리 | 온라인 기자재 구매 및 비교견적 | 온라인 견적 비교, 구매 지원(예정) | 미제공 | 미제공 |
| 기자재 관리 | 기자재 업체 온라인 입점 | 제공 (중소기업, 신규 업체 입점) | 미제공 | 미제공 |
| 취업 알선 | 미용 디자이너 구인·구직 매칭 | AI 기반 취업 알선 (예정) | 미제공 | 미제공 |

**노터스타일의 차별점**: 이들 모두가 **예약관리**에 집중하는 반면, 노터스타일은 **시술 기록 + AI 포트폴리오**라는 미개척 영역에 집중하고, 기자재 소싱과 구인구직까지 종합적으로 제공.

## 4. 제품 비전 -- AI 핵심 기능

### 4.1 AI 페이스 스왑 (초상권 보호 포트폴리오)
- **기술**: Replicate API (`codeplugtech/face-swap` 모델) -- Stable Diffusion AI in-paint 기반
- **작동 방식**: 시술 사진의 안면 영역을 자동 인식 → AI로 자연스럽게 얼굴 교체
- **가치**: 초상권 침해 없이 풍성한 포트폴리오 생성, 모델 섭외 비용 제거
- **비용**: 건당 ~$0.0027, 월 100장 기준 ~$0.27

### 4.2 AI 스타일 노트 (시술 사진 위 기록)
- **작동 방식**: 시술 사진 위에 직접 시술 내용/영역 기록
- **가치**: 텍스트나 기억에만 의존하던 시술 관리를 시각적/누적적으로 고도화

### 4.3 AI 음성 메모 구조화
- **기술**: OpenAI Whisper (음성→텍스트) + GPT-4o Structured Output (텍스트→JSON)
- **작동 방식**: 30초 음성 녹음 → 자동으로 구조화된 시술 데이터 생성
- **가치**: 바쁜 시술 중에도 빠른 기록 가능
- **프라이버시**: 음성 파일은 텍스트 변환 후 즉시 삭제
- **비용**: 하루 10건 × 30초 = $0.03/일, $0.66/월

### 4.4 AI 스타일러 (미래)
- **기술**: AI 이미징 기술
- **작동 방식**: 고객에게 다양한 스타일 제안과 미리보기 제공
- **가치**: 상담 품질 향상, 고객 유치 능력 강화

### 4.5 AI 상담 챗봇 (미래)
- **작동 방식**: 24/7 자동 고객 응대 (부재중 전화 처리, 예약, Q&A)
- **가치**: 시술 중에도 고객 문의 누락 방지

#### Instagram 포트폴리오 연동 (Phase 2 핵심)

디자이너의 기존 Instagram 게시물을 선택적으로 불러와 포트폴리오를 즉시 구성할 수 있는 기능.
**콜드 스타트 문제 해결**: 신규 가입 디자이너도 기존 Instagram 작업물로 풍성한 포트폴리오를 바로 완성.

| ID | 기능 | 설명 |
|----|------|------|
| F-020 | Instagram OAuth 연동 | Instagram Graph API를 통한 계정 연결 (비즈니스/크리에이터 계정) |
| F-021 | Instagram 게시물 선택적 불러오기 | 게시물 목록 조회 → 원하는 게시물 선택 → 포트폴리오에 등록 |
| F-022 | 디자이너 통합 포트폴리오 프로필 | Note-a-Style 시술 기록 + Instagram 게시물을 하나의 프로필로 통합 표시 |

**기술 요구사항**:
- Instagram Graph API (Meta 개발자 앱 심사 필요, 2-4주)
- Access Token 자동 갱신 (60일 만료 주기)
- 포트폴리오 소스 구분: `source: 'noteastyle' | 'instagram'`

**포트폴리오 소스 통합 구조**:
```
디자이너 포트폴리오
├── Note-a-Style 시술 기록 (자체 촬영/AI 페이스 스왑)
├── Instagram 게시물 (선택적 불러오기)
└── (향후) 블로그, 틱톡 등 추가 SNS
         │
         ▼
    통합 포트폴리오 프로필
         │
         ▼
    구인구직 매칭 (Phase 3)
```

## 6. 핵심 사용자 플로우

### 6.1 시술 기록 입력 (Core Flow)

바쁜 뷰티샵 환경에 최적화된 세 가지 입력 방식:

| 우선순위 | 방법 | 소요 시간 | 시나리오 |
|---------|------|----------|---------|
| 1순위 | 큰 버튼 탭 | 1초 | 바쁜 시간(10-14시), 팔꿈치/장갑 착용 중 |
| 2순위 | 사진/영상 촬영 | 3초 | 시술 직후 즉시 기록, 타입 자동 "after" |
| 3순위 | 음성 메모 | 30초 | 한가한 시간, 시술 후 일괄 정리 |

```
시술 완료
  │
  ├─ [방법 A] 빠른 기록 (/record)
  │   고객명 입력 → 시술 종류 탭 → (제품 선택) → 저장 → 사진 촬영
  │
  ├─ [방법 B] 상세 기록 (/treatments/new)
  │   고객명 + 전화번호 → 시술 종류 + 상세 → 제품/부위/시간/가격 → 저장 → 사진 촬영
  │
  └─ [방법 C] 음성 메모 (/record 내 VoiceMemo)
      녹음 30초 → Whisper → GPT-4o → 자동 폼 채우기 → 저장
```

### 6.2 AI 페이스 스왑 플로우

```
시술 사진 확인 (/treatments/[id])
  └→ "AI 페이스 스왑" 버튼 클릭
      └→ 소스 얼굴 이미지 업로드
          └→ POST /api/face-swap (Replicate API)
              └→ 3초 간격 폴링 (GET /api/face-swap/status/{id})
                  └→ 완료 시 face_swapped_url 자동 저장
                      └→ 원본/AI변환 나란히 표시
```

### 6.3 포트폴리오 플로우

```
[소스 A] 시술 상세 페이지 → "포트폴리오 추가" 클릭
  └→ 포트폴리오 갤러리에 등록

[소스 B] Instagram 연동 (Phase 2)
  └→ 설정에서 Instagram 계정 연결 (OAuth)
      └→ 게시물 목록 조회 → 원하는 게시물 체크
          └→ 선택한 게시물이 포트폴리오에 등록

통합 포트폴리오 갤러리
  └→ 공개/비공개 토글
      └→ SNS 공유 (Web Share API)
          └→ (Phase 3) 구인구직 프로필로 활용
```

## 12. 법적 검토 현황

### AI Face Swap 법적 검토 완료
- AI Face Swap 기술을 활용한 마케팅 콘텐츠 제공은 초상권 침해 가능성이 있어 **변호사 자문을 통해 법적 검토 완료**
- 변호사 자문 결과: **비식별화된 AI 변환 기술을 활용할 경우 초상권 침해가 성립되지 않으며, 합법적으로 활용이 가능함을 확인**
- 향후 정식 서비스 런칭 시에도 지속적인 법률적 검토 및 가이드라인을 마련하여 리스크를 최소화할 예정
- 정식 서비스 런칭 및 매칭 단계에서 이용 약관에 관련 이슈를 명시하여 사전 동의를 확보하고, 법적 리스크를 철저히 관리할 계획

## 13. 마케팅 및 시장 진입 전략

### 13.1 핵심 마케팅 전략
1. **Face Swap을 통한 차별화된 AI 마케팅 콘텐츠 제공 부각**
   - 초상권 문제가 없는 AI 페이스 스왑 기술을 활용한 마케팅 콘텐츠 제공을 핵심 포인트로 활용
   - 타 업체가 보유하지 않은 기능으로 리뷰어, 체험단 모집, 블로그 마케팅 비용 절감

2. **무료 사용 프로모션 적용**
   - 매장 차원: 신규 도입 시 월 사용료 **3개월 무료**
   - 개인 신규 도입 시 **3개월간 face swap 기능 10건 무료 제공** 후 SNS 공유 시 **20건 추가 제공**

3. **대학과의 전략적 제휴**
   - 전국 고등학교, 대학교 미용 관련학과와 협약하여 학생 및 졸업생 대상 무료 체험 프로그램 운영
   - 노터스타일의 시술기록 기능을 통해 학습내용을 자연스럽게 기록
   - 졸업 후 창업 시 자연스러운 플랫폼 유입 유도

4. **신규 매장 오픈단계부터의 컨설팅 연계**
   - 미용실 창업 초기 단계부터 BI 컨설팅, 마케팅 전략 수립 등의 서비스를 도입 패키지로 제공
   - 신규 오픈 시장(분기당 1,500개) 즉각적인 도입 가능성 활용하여 집중적인 마케팅 진행

5. **기자재 공급업체 전략적 입점 유도**
   - 경쟁력 있는 가격을 제시하는 영세 기자재 업체들에게 플랫폼 내 우선 입점의 기회 제공
   - 시장 초기 활성화와 가격 경쟁력을 확보하여 고객의 유입 요인 중 하나로 선순환 구조 창출
