## 1. Background & Motivation

### Problem Statement

현재 메뉴 구조가 뷰티샵 디자이너의 일상 워크플로우와 맞지 않음:

- **핵심 기능 접근성 부족**: "시술 기록"이 하단 탭에 없고 사이드바에 숨어있음
- **부차적 기능이 주요 위치 차지**: "탐색(Explore)"이 하단 탭 5개 중 하나를 차지
- **네이밍 혼란**: "작업(tasks)"이 실제로는 예약 보드인데 이름이 모호
- **헤더 비일관성**: 메인 페이지와 서브 페이지 간 헤더 구조가 다름
- **사이드바 구조 불분명**: 작업 메뉴와 관리 메뉴의 구분이 직관적이지 않음

### Impact

| 문제 | 영향도 | 사용자 영향 |
|------|--------|------------|
| 시술 기록 접근 어려움 | HIGH | 핵심 기능인데 2탭 이상 필요 |
| 예약 탭 네이밍 혼란 | MEDIUM | "작업"이 뭔지 직관적이지 않음 |
| 탐색이 주요 탭 차지 | MEDIUM | 매일 쓰지 않는 기능이 1등석 |
| 헤더 불일관 | LOW | 페이지마다 다른 UX |

### Success Criteria

- [ ] 하단 탭 5개가 일상 워크플로우 순서대로 배치
- [ ] 사이드바에 전체 메뉴가 논리적으로 그룹화
- [ ] 상단 헤더가 인스타그램 스타일로 모든 메인 페이지에서 일관
- [ ] "+" 버튼으로 빠른 액션 시트 (예약/시술/고객 생성)
- [ ] 기존 모든 페이지에 대한 접근 경로 유지 (기능 손실 없음)
- [ ] `npm run build` 성공

## 2. Scope

### In Scope

#### 2-1. 하단 탭 재구성

| 현재 | 변경 후 | 비고 |
|------|---------|------|
| 고객 | 홈 | 대시보드 (오늘 요약) |
| 탐색 | 예약 | 예약 보드 (날짜별) — "작업" 리네이밍 |
| 홈 | + (FAB) | 빠른 액션 시트 (예약/시술/고객 생성) |
| 작업 | 고객 | 고객 목록 |
| 포트폴리오 | 갤러리 | 포트폴리오 갤러리 — 리네이밍 |

**탭 순서**: `홈 | 예약 | + | 고객 | 갤러리`

#### 2-2. 상단 헤더 통일 (Instagram 스타일)

```
┌─────────────────────────────────┐
│  매장명/로고              ☰     │
└─────────────────────────────────┘
```

- 왼쪽: 매장 이름 또는 로고 (현행 유지)
- 오른쪽: 햄버거 메뉴 (사이드바 오픈)
- 모든 메인 페이지(홈, 예약, 고객, 갤러리)에서 동일하게 표시
- 서브 페이지(시술 상세 등)에서는 `< 뒤로가기 | 페이지 제목` 형태

#### 2-3. "+" 빠른 액션 시트

가운데 탭의 "+" 버튼 클릭 시 바텀 시트 표시:

| 액션 | 이동 경로 |
|------|----------|
| 예약 등록 | /reservation |
| 시술 기록 | /treatments/new |
| 고객 등록 | /customers (신규 모달 or 페이지) |

#### 2-4. 사이드바 메뉴 재구성

```
포트폴리오 (대구분)
  탐색 (Explore)        → /explore
  포트폴리오 갤러리     → /portfolio
  이력서 관리           → /profile

작업 메뉴 (대구분)
  홈 (대시보드)         → /
  예약 보드             → /tasks
  예약 등록             → /reservation
  고객 목록             → /customers
  시술 기록 목록        → /treatments
  새 시술 기록          → /treatments/new
  전체 예약 목록        → /tasks/all

매장 관리 (대구분)
  매장 설정             → /settings/shop
  시술 메뉴 관리        → /settings/services
  멤버 관리             → /settings/shop (멤버 탭)
  휴지통                → /trash

설정 (대구분)
  테마 (시스템/라이트/다크) — 인라인 토글
  관리자 설정 (admin only) → /admin

로그아웃 | 버전
```

### Out of Scope

- 새로운 페이지/기능 추가 (기존 페이지 재배치만)
- 로딩 성능 최적화 (별도 태스크)
- UI 디자인 리뉴얼 (레이아웃/구조만 변경)
- 알림 기능 (향후 확장 예정)

## 3. Technical Approach

### 변경 파일 목록

| # | 파일 | 변경 내용 |
|---|------|----------|
| 1 | `components/BottomNav.tsx` | 탭 5개 재구성 + "+" FAB 추가 |
| 2 | `components/AppHeader.tsx` | 모든 메인 페이지에서 표시되도록 확장 |
| 3 | `components/SidebarDrawer.tsx` | 메뉴 그룹 재구성 |
| 4 | `components/QuickActionSheet.tsx` | **신규** — "+" 버튼 바텀 시트 |
| 5 | `app/layout.tsx` | QuickActionSheet 추가 |
| 6 | `app/treatments/page.tsx` | 자체 sticky header 제거 → AppHeader 활용 |
| 7 | `app/portfolio/page.tsx` | 자체 header 확인/통일 |
| 8 | `app/customers/page.tsx` | 자체 header 확인/통일 |

### 구현 순서

1. **BottomNav.tsx** — 탭 구조 변경 + "+" 버튼 추가
2. **QuickActionSheet.tsx** — 빠른 액션 바텀 시트 컴포넌트
3. **AppHeader.tsx** — 메인 페이지 목록 확장
4. **SidebarDrawer.tsx** — 메뉴 재구성
5. **각 페이지 header 통일** — 중복 헤더 제거
6. **빌드 & 테스트**

### Risk & Mitigation

| 리스크 | 대응 |
|--------|------|
| 기존 사용자 혼란 (메뉴 위치 변경) | 사이드바에 전체 메뉴 유지로 접근성 보장 |
| "+" 버튼 UX 어색함 | 인스타그램/카카오 등 검증된 패턴 차용 |
| 서브 페이지 헤더 불일관 | 서브 페이지용 PageHeader 컴포넌트 통일 |
